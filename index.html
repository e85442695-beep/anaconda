4 GB VRAM. No hardware Ray Tracing.

What Anaconda changes

Built on codec-d/cool_fox (pareto-residency) and VIctory, focused on keeping 4 GB Turing GPUs playable without RT cores.

Strict 4 GB VRAM discipline & world reserves

victory-gpu/src/resource.rs · shadow.rs

VICTORY_VRAM_MB caps the host DXGI budget, and resource::room() enforces real VRAM usage plus render-target and buffer reserves even when VICTORY_TEXTURE_BUDGET_MB is set. Shader-written buffers down to 64 KiB stay resident in VRAM instead of crossing PCIe Shared RAM.

16 MiB best-fit tiled texture pools

victory-gpu/src/tiles.rs

Instead of 64 MiB pools stranding up to 376 MiB of dead VRAM, <= 6 GiB GPUs automatically allocate 16 MiB heaps with best-fit packing—cutting live heap footprint from 832 MiB down to 480 MiB at 96% utilization.

Zero-dependency Series S FSR + RCAS upscaler

victory-hle/src/modules/fidelityfx.rs · external.rs

Implements amd_fidelityfx_loader_xbox.dll natively in Rust backed by a D3D12 cs_5_1 compute shader with 5-tap clamped RCAS sharpening, NaN/Inf recovery, and multi-threaded thin command-list translation.

AMD FSR 3-style Optical Flow Frame Generation

victory-gpu/src/framegen.rs

A 4-level coarse-to-fine Zero-Mean SAD bidirectional optical flow pyramid, GPU scene-cut detector, and 3-hypothesis disocclusion-aware synthesizer operating strictly on the HUD-less 3D plane (Plane 0) before UI compositing (Plane 1).

Software indirect lighting without Ray Tracing

victory-gpu/src/ambient.rs · settings-very-low.xml

Zero-VRAM No-RT mode (VICTORY_RT_NO_ARENAS=1) paired with software diffuse GI and CS_RayMiss specular reflections stand-in so indoor characters and interiors remain legible without RT hardware.

Zero-VRAM on-screen FPS / MS / VRAM HUD

victory-gpu/src/fps_hud.rs

Toggle live at any time with F4. Renders native FPS, generated FPS (when FrameGen is active), frametime, and live VRAM usage directly onto the final swap-chain frame.

Build & run

Choose a launch profile below, point VICTORY_GAME_DIR to your own Xbox Series dump, and run Play-Anaconda.cmd.

Requirements

  • OS: Windows 10 / 11 x64
  • CPU: AVX2-capable processor (tested on Ryzen 5 5500)
  • GPU: Direct3D 12 with Shader Model 6.6 & Mesh Shaders, 4 GB+ VRAM (no RT cores required)
  • Toolchain: Rust (pinned in rust-toolchain.toml), MSVC C++ Build Tools, Windows SDK
  • Game data: Your own Xbox Series dump (zero game files are stored in this repo)
Variable Default Purpose
VICTORY_DISPLAY_MODE 1280x720 Display resolution reported to the title via DXGI
VICTORY_VRAM_MB 3050 Caps local DXGI VRAM budget for 4 GB cards (MiB)
VICTORY_TILES_HEAP_MB 16 Tiled texture heap granularity (16 MiB best-fit on <= 6 GiB GPUs)
VICTORY_TEXTURE_BUDGET_MB 900 Upper cap on texture VRAM while honoring DXGI & RT/buffer reserves
VICTORY_RELAY 2 Stage-2 per-range async relay avoiding full-flight GPU stalls
VICTORY_FSR_SCALE / _SHARPEN 1.35 / 0.55 Internal FSR scale factor and RCAS sharpening strength
VICTORY_FRAME_GEN 0 (or 1 = 2×) AMD FSR 3-style Optical Flow Frame Generation (0=off, 1=2x, 3=3x, 4=4x)
VICTORY_FPS_HUD right On-screen FPS / MS / VRAM overlay (live toggle with F4)
